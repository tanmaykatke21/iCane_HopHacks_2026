# iCane

A phone-camera walk-assist cane that gives blind and low-vision users real-time awareness of their surroundings.

iCane turns a standard cane into a smart navigation aid by mounting a phone to the cane. The phone camera observes the path ahead, a vision model identifies relevant hazards, and text-to-speech delivers concise audio feedback.

## How It Works

1. Attach a phone to the cane with a simple clamp.
2. Open the web app and grant camera access.
3. Start monitoring to continuously capture the scene ahead.
4. iCane classifies hazards and speaks meaningful changes in the path.
5. Request a fuller description of the surroundings when needed.

## Capabilities

The system can help identify:

- Objects directly in the walking path
- People approaching from the side
- Stairs and curbs
- Low overhangs
- Doors and nearby obstacles
- Cluttered floor conditions

The user can request an on-demand scene description with the visible button, a double tap, or a shake gesture.
